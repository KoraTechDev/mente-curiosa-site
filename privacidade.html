Política de Privacidade

Última atualização: 2 de novembro de 2026.

Quem usa o app

O app mente-curiosa é uma ferramenta interna do canal Mente Curiosa. Só a equipe do canal faz login nele. O app não é oferecido ao público.

Quais dados acessamos

Com a sua autorização (escopo yt-analytics.readonly), o app lê as métricas dos vídeos do canal que fez login: visualizações, duração média de visualização, porcentagem assistida, curtidas, compartilhamentos, comentários e inscritos ganhos.

O app não acessa e-mails, contatos, arquivos nem dados de outros canais. Ele também não publica, altera ou apaga nada no YouTube.

Como usamos e guardamos

  • As métricas servem só para acompanhar o desempenho dos vídeos do próprio canal.
  • Os dados e o token de acesso ficam salvos apenas no computador da equipe. Não são enviados a servidores de terceiros.
  • Não vendemos, não compartilhamos e não usamos os dados para publicidade.

Uso de dados das APIs do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

Você pode remover o acesso a qualquer momento em myaccount.google.com/permissions. Para pedir a exclusão dos dados guardados, escreva para o contato abaixo.
